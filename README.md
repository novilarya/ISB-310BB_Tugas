Pada minggu ini dipelajari terhait PHP, Session, dan Cookies, dengan tugas di minggu ini melanjutkan studi kasus yang diambil kemarin dengan penyesuaiian pada HTML yang dirubah menjadi PHP dan penambahan bebrapa file baru yaitu login.php, controller/proses_login.php, dan controller/proses_logout.php. Dengan detail penjelasan di bawah ini.
1. Penambahan kode php pada index.php.
   Potongan kode pada bagian atas index.php tersebut berfungsi sebagai pengatur status login user di halaman utama dengan memulai mekanisme session menggunakan session_start() agar data yang tersimpan di server dapat diakses. Selanjutnya, terdapat struktur logika kondisional yang menggunakan operator null coalescing (??) untuk memeriksa apakah terdapat data user dalam variabel global $_SESSION['user']. Jika data tersebut ditemukan, maka nilainya akan dimasukkan ke dalam variabel $user, namun jika kosong, variabel $user akan diatur sebagai null untuk menandakan bahwa user belum melakukan login.
2. Penambahan button login dengan penyesuaian ketika sudah login atau belum login.
   Pada navbar saat ini terdapat logika PHP untuk mengubah tampilan menu berdasarkan status login pengguna. Baris awal merupakan navigasi dengan logo "NARENT" dan menu pada umumnya seperti "Tentang Kami" serta "Layanan Kami", diikuti oleh blok logika if (!$user) yang akan menampilkan tombol login jika pengguna belum masuk. Sebaliknya, jika pengguna sudah login, kode akan menampilkan menu dropdown berbentuk ikon profil yang berisi tautan ke halaman profil dan proses logout, serta diakhiri dengan ikon keranjang wishlist yang dilengkapi dengan lencana (badge) dinamis untuk menunjukkan jumlah item.
3. Penambahan file login.php yang merupakan halaman login.
   Pada halaman login ini, dirancang untuk menerima input-an user untuk melakukan login, namun sebelum ini, kode pada halama ini memeriksa terlebih apakah pengguna sudah login sebelumnya melalui fungsi isset($_SESSION['user']), yang jika terdeteksi maka akan langsung mengalihkan user untuk kembali ke halaman utama. Di dalam elemen <body>, terdapat formulir yang dikirim menggunakan metode POST ke file proses atau pada controller/proses_login.php yang dilengkapi dengan komponen Bootstrap Alert untuk menampilkan pesan kesalahan jika user salah dalam meng-input username atau password. Fitur penting lainnya adalah pengisian otomatis (auto-fill) pada kolom username yang membaca data dari $_COOKIE['remember_username'] jika sebelumnya user pernah melakukan login dan menceklis checkbox "Remember Me", serta adanya checkbox "Remember Me" bagi pengguna yang ingin menyimpan identitas login di browser.
4. Penambahan file controller/proses_login.php.
   File ini berjalan ketika user sudah melakukan pengiriman data pada halaman login.php dan bertindak sebagai pengontrol di sisi server yang menangani pengiriman data dari formulir login dengan mengambil input username, password, dan status remember me melalui variabel global $_POST. Kode melakukan validasi terhadap input-an user baik username dan password, di mana jika cocok, sistem akan mendaftarkan username ke dalam session dan mengatur cookie berdurasi 3600 detik (1 jam) apabila opsi remember me dicentang. Jika input-an tidak sesuai atau salah dengan username atau password yang valid, sistem akan mengirimkan instruksi pengalihan kembali ke halaman login dengan menyertakan parameter error=1 agar pesan kesalahan dapat ditampilkan kepada user.
5. Penambahan file controller/proses_logout.php.
   File ini berjalan ketika user sudah melakukan login dan mengklik button logout pada navbar. Kode pada file ini bertujuan untuk membersihkan seluruh data aktivitas pengguna secara menyeluruh dengan cara memulai session kembali, kemudian mengosongkan variabel global $_SESSION dengan array kosong, dan menghancurkan atau menghapus session tersebut secara permanen menggunakan session_destroy(). Selain menghapus data di sisi server, kode ini juga menghapus jejak login di sisi klien atau user dengan mengatur masa berlaku cookie "username" menjadi waktu di masa lalu (time() - 3600). Terakhir, pengguna akan diarahkan kembali ke halaman beranda menggunakan fungsi header() sehingga tampilan navbar akan kembali ke status belum login.
6. Penambahan kode pada css/style.css
   Potongan kode pada css/style.css yang ditambahkan merupakan pengatur pada elemen antarmuka, khususnya pada tombol login yang menggunakan warna latar belakang putih transparan (rgba) dan teks berwarna gelap. Terdapat juga deklarasi pseudo-class :hover yang meningkatkan tingkat kecerahan latar belakang tombol saat kursor berada di atasnya/hoover untuk mempertegas button tersebut. Selain itu, kode ini mengatur tampilan teks placeholder pada kolom input dengan memberikan warna abu-abu spesifik dan ukuran font 0.9rem.
